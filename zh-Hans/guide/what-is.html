什么是 NetonAPI ​

NetonAPI 是一个开源、自托管的大模型 API 中转站。你把采购来的上游账号（OpenAI、Anthropic、Google、国内厂商或别的中转站）接进来， 给自己的用户发 API Key、按 token 计费；用户用一个 Key 就能调用所有主流模型，官方 SDK 和 Claude Code 这类工具改个地址就能用。

它自带两个界面：

  • 管理后台：给运营用。管渠道、管定价、给大客户谈价、看收入成本毛利、处理账务。
  • 网站与用户控制台：给买家用。注册登录、看模型与价格、创建 API Key、看用量与账单、充值。

Neton Cloud 就是用 NetonAPI 运营的一个中转站，可以直接注册看看实际效果。

和别的中转站有什么不一样 ​

大多数开源中转站从「把请求转出去」出发，计费是在转发上叠加几层倍率。 真正运营一个中转站，每天操心的是另外几件事：

  • 每个模型卖多少钱？拿货多少钱？这一单赚没赚？
  • 给大客户打的折扣，会不会在某条渠道上卖亏？
  • 用户看到的价格和他的账单对不对得上？

NetonAPI 从一开始就围绕这几个问题设计：

运营的问题NetonAPI 的做法
售价怎么定以官方价为锚：售价 = 官方价 × 加价率；优惠写成「官方价 N 折」，官方价调整时自动跟随
拿货价是多少每条渠道记录真实成本：官方价折扣、自动拉上游中转站的价目、或按模型手填
会不会卖亏任何定价保存前按真实会走的每条渠道核算毛利，低于成本直接拒绝
账对不对得上扣费 = tokens × 用户看到的单价，价格页、控制台、账单是同一个数
出了故障怎么办先预留、后结算；进程崩溃自动恢复，说不清的账进人工复核，不会重复扣费

技术形态 ​

  • 服务端用 Kotlin/Native 编译成单个原生可执行文件，运行时不需要 JVM。
  • 数据库只用 PostgreSQL；Redis 可选（多实例时共享限流）。
  • 管理后台与网站前端是两个 Next.js 应用。
  • 许可：Apache-2.0。

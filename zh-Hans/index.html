以官方价为锚定价

售价写成「官方价 × 加价率」，给一组用户或单个大客户的优惠写成「官方价 N 折」。官方价调整时自动跟随，不用换算一层层倍率。

🛡️

亏本的价格保存不了

每条渠道记录真实拿货价。任何定价保存前按真实会走的每条渠道核算毛利，低于成本直接拒绝；定价体检列出最差毛利。

🧾

展示的单价就是扣费的单价

扣费 = tokens × 用户看到的单价，价格页、控制台、账单三处是同一个数，客户可以逐笔对账。

🔒

两阶段账务

先预留、后结算，定价快照随请求冻结；进程崩溃自动恢复，说不清的账进人工复核，不会自动退款也不会重复扣费。

🤝

协议定价

搜一个用户，逐模型或批量设「官方价 N 折」，实时显示他的价格与毛利；专线与特价直接指定到 API Key。

🔁

三种协议任意互转

OpenAI、Anthropic、Gemini 原生入口，工具调用、图片、thinking、缓存用量跨协议保真；Claude Code 与各家官方 SDK 直接可用。
